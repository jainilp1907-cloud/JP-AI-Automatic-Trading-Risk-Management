# JP — AI Automatic Trading Risk Management

A Streamlit educational stock-analysis prototype with a JP monogram brand, historical market data, moving averages, RSI, a transparent rule-based BUY WATCH / HOLD / SELL WATCH indicator, and an illustrative risk calculator.

## Run on Windows

1. Install Python 3.11 or newer.
2. Extract this ZIP.
3. Open the extracted folder in VS Code.
4. Open Terminal > New Terminal.
5. Run:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

6. Open the local address printed in the terminal (usually http://localhost:8501).

## Important

This is a learning and paper-analysis prototype. Signals are generated by simple technical rules, not a validated predictive AI model. It does not place trades and must not be treated as financial advice. Historical data and indicators cannot guarantee future performance.
